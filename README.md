
# Suyash Vishnoi — Developer Portfolio

A responsive, animated portfolio showcasing full-stack web development,
software engineering, and AI/ML projects.

## Tech Stack

- React and Vite
- Three.js with React Three Fiber and Drei
- Framer Motion
- Lucide React
- CSS

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Deployment

Deploy as a Static Site on Render.

- Build command: `npm install && npm run build`
- Publish directory: `dist`

## Before Publishing

1. Replace placeholder GitHub URLs with actual project repositories.
2. Add your real LinkedIn URL and email address.
3. Verify the project descriptions, skills, and experience details.
4. Add a resume link if you want recruiters to download your resume.
